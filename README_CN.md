## 项目简介

Whybrary 只为一个人、一台机器、一个目标而做：让你的原因足够清晰，清晰到可以行动。

它不打算把长笔记、书签和任务堆在一起，而是刻意保持简单：

- 用一个可连接的脑图整理动机、原因和方向
- 用一个轻量清单把这些原因落成短小、可勾选的动作

## 你可以用它做什么

- 创建多个互相独立的空间
- 在本地脑图里添加并连接节点
- 在脑图旁边维护简短的单行 To-Do
- 切换白天与夜晚主题
- 全程离线使用

## 隐私

- 没有账号
- 没有同步
- 没有上传
- 不依赖联网服务
- 数据只保留在你的设备上

## 当前状态

Whybrary 目前处于持续迭代中的早期阶段。桌面应用已经可以使用，界面和交互还会继续逐步打磨。

## 本地运行源码

如果你想直接在本地运行项目：

```bash
npm install
npm run tauri dev
```
